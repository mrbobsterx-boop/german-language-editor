# German Language Editor

Browser-based German learning text editor.

## Current features

- German text editor
- Select a word, phrase, or sentence
- Selection popup
- Add a note/translation into the text
- Save selected words to the learning dictionary
- Learning words are shown in the right panel
- Save and reopen the complete document as JSON
- No full-text translation panel

## Structure

```text
german-language-editor/
├── index.html
├── data/
│   └── words.json
└── README.md
```

## Local use

Open `index.html` in a browser.
